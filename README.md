# InGameBlocks (Fabric, Minecraft 26.3) — автор: norrmi

Свои блоки прямо в игре: картинка + название + тип + звук. Блоки хранятся на компьютере автора
(`.minecraft/ingameblocks/`), а при желании раздаются другим игрокам с этим модом на сервере.

## Сборка
Нужен **JDK 25** (не 27). `gradlew build` → `build/libs/ingameblocks-2.0.0.jar`. Запуск для теста: `gradlew runClient`.
Мод нужен **и на сервере, и у игроков**. В одиночной игре он работает сам.

## Как пользоваться
* **B** — меню. Вкладки **My blocks** (свои) и **Shared blocks** (чужие, которые раздают). Свои раздаваемые блоки подсвечены синим.
* Перетащите в окно картинки PNG / JPG / **WebP** (16, 32, 64, 128, 256 px; неквадратные обрежутся по центру) или экспортированные `.zip`.
* ЛКМ — **выбрать** блок (один клик). Двойной клик или **ПКМ** — переименовать свой блок. Shift+клик — взять стак. **Edit** — редактор:
  название, id, **тип** (полный блок, колонна, стекло, полублок, ступеньки, забор, ковёр, растение/цветок, голова, сундук, наковальня, поршень),
  **звук** любого ванильного блока (по умолчанию — звук типа), раздача, и **отдельная картинка на каждую сторону**. Свои блоки можно менять в любой момент, даже после перезахода: блок опознаётся по внутреннему `uid` в `library.json`, а не по имени файла.
* **Paint** — встроенный редактор текстур: кисть (размер, непрозрачность, мягкость, круглая/квадратная, зеркало), ластик, заливка,
  пипетка (или ПКМ), линия, прямоугольник (Shift — закрашенный), отмена/повтор (Ctrl+Z / Ctrl+Y), масштаб колесом, сдвиг средней кнопкой.
  Перерисовывать можно и свои, и ванильные, и чужие текстуры (через **Choose…** → вкладки Мои / Minecraft / Общие).
* **Export** — блок в `.zip` (папка `ingameblocks/exports`), друг может перетащить его в своё меню.

## Команды
`/igb` (= `/ingameblocks`): `menu`, `folder`, `reload`, `list`, `give <id> [кол-во]`, `share <id> on|off`, `rename <id> <название>`, `export <id>`, `import <файл>`.
Для админов: `/igbadmin list`, `/igbadmin free <тип> <номер>`.

## Как это устроено
Minecraft не умеет добавлять новые блоки после запуска, поэтому у мода по одному блоку на каждый тип
(`ingameblocks:cube`, `ingameblocks:slab`, …), а конкретный рисунок хранится в свойстве `design`.
Места выдаются по мере добавления блоков — в `/give` больше нет `slot_999`. Ресурспак с текстурами
строится в памяти и подключается **только на сервере с этим модом**; в списке паков он называется «InGameBlocks (Server-side)».

Ограничения: поршень декоративный (не толкает), блоки из старой версии CustomBlocks, уже поставленные в мире, не переносятся
(картинки из `customblocks/` копируются автоматически).
